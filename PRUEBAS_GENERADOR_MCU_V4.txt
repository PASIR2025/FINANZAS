SIMUPLC 1.2 — CORRECCIÓN DEL GENERADOR MCU V4

PROBLEMA CORREGIDO
- Arduino IDE insertaba un prototipo automático de runPID(PIDState...) antes de declarar PIDState.
- Resultado anterior: “PIDState was not declared in this scope”.

CORRECCIONES
1. FBD
- Se eliminó el helper PIDState/runPID que no era usado por el motor FBD.
- El PID FBD continúa usando el motor runPidNode con arreglos internos.
- AI de Arduino AVR se adapta automáticamente a ADC 0–1023.
- AI de ESP32 conserva ADC 0–4095.

2. LADDER
- runPID ya no recibe PIDState como parámetro.
- Recibe referencias a integral, error previo, tiempo y salida, evitando el fallo del preprocesador de Arduino.
- Se mantiene el estado independiente de cada bloque PID.

3. PWM
- Arduino UNO/Nano/MEGA/Leonardo/ATmega328P: analogWrite 0–255.
- ESP32 Arduino Core 3.x: ledcAttach + ledcWrite por pin.
- ESP32 Arduino Core 2.x: ledcSetup + ledcAttachPin + ledcWrite por canal.

VALIDACIONES EJECUTADAS
- JavaScript del generador: sintaxis válida.
- Navegador: sin errores al generar código.
- FBD AI1 + AI2 + PID + PWM1 generado para Arduino UNO.
- FBD AI1 + AI2 + PID + PWM1 generado para ESP32.
- Ladder AI1 + AI2 + PID + PWM1 generado para Arduino UNO.
- Ladder AI1 + AI2 + PID + PWM1 generado para ESP32.
- Compilación sintáctica C++ con stubs de API Arduino para AVR.
- Compilación sintáctica C++ con stubs de ESP32 Core 2.x.
- Compilación sintáctica C++ con stubs de ESP32 Core 3.x.
- Prueba de humo de la aplicación principal: correcta, sin errores de página.

PRUEBA FÍSICA RECOMENDADA
- Arduino UNO: AI1=A0, AI2=A1, PWM1=D3.
- ESP32: AI1=GPIO36, AI2=GPIO39, PWM1=GPIO23.
- Circuito: AI1→PV, AI2→SP, PID→PWM1.
