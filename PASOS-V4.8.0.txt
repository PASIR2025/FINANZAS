PASIR Gestión V4.8.0 — instalación

1. Reemplaza los archivos del repositorio GitHub con esta carpeta completa.
2. En Supabase > SQL Editor > New query abre SUPABASE-PARCHE-V4.8.0.sql.
3. Copia todo el SQL, pulsa Run y confirma que salga: PASIR V4.8.0 listo.
4. Abre PASIR y comprueba abajo que diga V4.8.0.
5. Crea un movimiento de prueba S/ 1, elimínalo y pulsa Sincronizar.
6. Cierra PASIR, vuelve a abrir y confirma que el movimiento NO reaparece.

No vuelvas a ejecutar supabase-schema.sql. El parche V4.8.0 no borra usuarios ni datos existentes.
